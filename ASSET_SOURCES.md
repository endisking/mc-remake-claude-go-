## Code references (MIT)

World generation follows open-source reimplementations of the vanilla 1.17 generator, ported to TypeScript
with credit in each file header:
- Cubitect/cubiomes — https://github.com/Cubitect/cubiomes — MIT (`licenses/cubiomes.txt`): biome layer rules,
  biome classification; also compiled locally as the reference for the biome test fixtures.
- SeedFinding (KaptainWutax, Neil) mc_biome_java / mc_terrain_java / mc_feature_java / mc_noise_java /
  mc_core_java — https://github.com/SeedFinding — MIT (`licenses/SeedFinding.txt`): noise, terrain, surface
  builders, ore decorators, structure placement.

## Libraries bundled in the client

- qrcode-generator (Kazuhiko Arase) — https://github.com/kazuhikoarase/qrcode-generator — MIT: draws the offline
  LAN pairing QR codes.
- jsQR (Cosmo Wolfe) — https://github.com/cozmo/jsQR — Apache-2.0: reads QR codes from the camera in browsers
  without BarcodeDetector.
